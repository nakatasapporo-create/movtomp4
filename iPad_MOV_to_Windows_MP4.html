MP4を保存する
うまく変換するためのポイント
  • 変換中はこの画面を閉じず、iPadを充電しておくと安心です。
  • 長い動画ほど時間と空きメモリが必要です。まず短い動画でお試しください。
  • 初回のエンジン読込にはインターネット接続が必要です。動画そのものは外部へ送信しません。
  • Windows 10では、保存したMP4を「映画＆テレビ」やVLCで再生できます。

動画は端末内で処理され、サーバーへ送信されません

出力形式：MP4 / H.264 / AAC / yuv420p
