うまく変換するためのポイント
  • 動画を選択した後、しばらく待ってください。アプリへ登録されるのに時間がかかります。
  • 変換中はこの画面を閉じず、iPadを充電しておくと安心です。
  • 長い動画ほど時間と空きメモリが必要です。まず短い動画でお試しください。
  • index.htmlとffmpegフォルダをGitHub Pagesへ置き、https://で開いてください。HTMLファイルの直接実行では変換できません。
  • 初回は変換エンジンを読み込むため、インターネット接続が必要です。
  • 動画がすでにH.264なら再圧縮せず、高速にMP4へ入れ替えます。HEVC動画だけH.264へ変換します。
  • Windows 10では、保存したMP4を「映画＆テレビ」やVLCで再生できます。

動画は端末内で処理され、サーバーへ送信されません

出力形式：MP4 / H.264 / AAC / yuv420p ・ iPad Safari対応版 v4.0
